# Dinny Alya Puteri — Portfolio

Personal portfolio built with Next.js, React, and Tailwind CSS.

## Run locally

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Where to edit content

- `lib/portfolio-data.ts`: projects, competition highlights, skills, contact links, and navbar links.
- `components/hero.tsx`: hero name, study program, semester, and intro.
- `components/about.tsx`: biography and education details.
- `public/profile.png`: profile photo.

## Deployment

Push the updated project to the GitHub repository connected to Vercel. Vercel should start a new deployment automatically.

## Notes

- The UINIC 8.0 entry is described as a competition project; no award or finalist result is claimed.
- Update the email and social profile URLs in `lib/portfolio-data.ts` if they change.
- Check that the Figma file is accessible to viewers before sharing the portfolio publicly.
